# LLMLOG

## 2026-05-23 — SR700 incomplete serial read diagnosis

**Symptom:** `roasted -debug` wrote init packet (`0xAA 0x55 ...`) then failed with `incomplete read, read 1, expected 14`.

**Root cause:** `sr700/sr700.go` `Read()` used a single `port.Read()` and required exactly 14 bytes. Serial reads are partial by design; the kernel had only 1 byte buffered when `Read()` returned.

**Fix:** Replaced with `io.ReadFull(s.port, s.buf)` so all 14 bytes are collected across multiple reads (respecting port inter-character timeout).

**If still failing after rebuild:** Increase `InterCharacterTimeout` in `cmd/roasted/main.go` from 100 to 500 ms (roaster slow to start streaming).

**Rebuild:** `go install ./cmd/roasted`

## 2026-05-23 — macOS serial open errors (ENOENT / SYS_IOCTL)

**ENOENT (`no such file or directory`):** USB device not enumerated yet, unplugged, or wrong path. After plug-in wait ~1–2s then `ls /dev/cu.wch*`. Use `/dev/cu.*` not `/dev/tty.*` on macOS.

**SYS_IOCTL invalid argument:** Transient failure opening port right after USB enumerate with `jacobsa/go-serial` + WCH CH340 on modern macOS. Reproducible intermittently; retry usually succeeds. Check nothing else holds the port: `lsof /dev/cu.wchusbserial110`.

**Verified working after ReadFull patch:** Connect + fan test completes; temp `0xFF00` displays as `-- F` (below 150°F).

**If EINVAL persists:** unplug/replug, wait, retry; or migrate to `go.bug.st/serial` (better macOS maintenance).

## 2026-05-23 — JSON Schema recipes + Makefile + lint

**Goal:** editor autocomplete and validation while writing recipe JSON, plus a single entry point for build/test/lint.

**Approach:** Go types in [`pkg/recipe.go`](pkg/recipe.go) are the source of truth. [`tools/schemagen/main.go`](tools/schemagen/main.go) uses [invopop/jsonschema](https://github.com/invopop/jsonschema) to reflect them into [`schemas/simple-recipe.schema.json`](schemas/simple-recipe.schema.json) and [`schemas/openroast-recipe.schema.json`](schemas/openroast-recipe.schema.json). Doc comments on each field become schema descriptions via `AddGoComments`. The schemas are committed; `make check-schemas` enforces drift detection.

**Layout decision:** schemas live in `schemas/` at the repo root rather than `generated/`. JSON Schema files are committed editor-facing contracts (like OpenAPI specs), not ephemeral build output. Each generated file carries `"$comment": "Code generated by tools/schemagen. DO NOT EDIT."` to signal intent.

**Editor wiring:** [`.vscode/settings.json`](.vscode/settings.json) maps `*.recipe.json` → SimpleRecipe schema and `*.openroast.json` → OpenRoast schema. [`.vscode/recipe.code-snippets`](.vscode/recipe.code-snippets) adds `step`, `cool`, and `recipe` snippets with enum-choice placeholders for fan/heat.

**`go generate` invocation:** `//go:generate go run ../tools/schemagen -src . -out ../schemas` in [`pkg/recipe.go`](pkg/recipe.go). The `-src` flag is needed because `go generate` runs from `pkg/` while `AddGoComments` wants the path relative to cwd.

**Module rename:** fork — module path is now `github.com/zcstarr/roasted` (was `jmhobbs`). All imports updated. The schema `$id` URLs use the same prefix so cross-repo `$ref` resolution stays consistent if anyone hosts these.

**Makefile + lint:** [`Makefile`](Makefile) is the single entry point — `help`, `build`, `install`, `test`, `generate`, `lint`, `check-schemas`, `check`. [`.golangci.yml`](.golangci.yml) uses golangci-lint v2 with `linters.default: standard` plus `misspell`, formatters `gofmt` + `goimports`. GitHub Actions (`.github/workflows/ci.yml`) runs `make check` on push/PR; Go version from `go.mod`. Pinned linter version: `v2.6.1`.

**Pre-existing lint fixes:** `defer port.Close()` and `defer f.Close()` triggered `errcheck`; rewrote both as `defer func() { _ = ...Close() }()`. Also `var secondsRemaining int = step.Duration` → `:=` for `staticcheck ST1023`.

**Verify:**
- `make generate` — writes both schemas
- Open `sr700-fan-test.recipe.json` in Cursor — autocomplete on step properties, enum dropdown on `heat`/`fan`, red squiggle on out-of-range values
- `make check` — lint, tests, and schema drift all pass
- Recipe runtime is unchanged; `LoadSimpleRecipe` still ignores the new `$schema` field (encoding/json skips unknown keys)
